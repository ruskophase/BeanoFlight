Evidence guide

Prediction is a different claim from observation.

Fully synthetic workflow

Training material, particle features, decisions, action records, scale values and capture outcomes are synthetic. A stored seed fixes each targeted particle’s outcome. Misses enter Pass-through.

Only an isolated simulation database can contain this stock.

Real material, estimated composition

Real receipts and entered measurements can coexist with image-derived features and reported controller actions. Without chute verification, output composition remains an expected profile.

Physical associations are not available. Synthetic monitoring never upgrades an expected count to a verified census. Archived sorter records can be imported through the read-only adapter; live integration remains a later milestone.

The example below keeps the historical 97% capture assumption. New training jobs use Simulation Settings (initially 99%). It uses synthetic fixture inputs to demonstrate the real-run expectation formula. It does not create real inventory or attach synthetic features to real portions.

10,000 tracked particles, 2,000 action attempts, 8,000 intentional passes: expected Selected = 1,940; expected Pass-through = 8,060, including 60 expected missed targets.
